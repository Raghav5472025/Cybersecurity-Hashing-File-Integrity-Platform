## Overall Learning 

During my 6-month SURE Trust internship in Cybersecurity, I worked on HashShield — a hashing and file security project. Through this I learned:

How SHA-256 hashing works and why it's used for file integrity
How bcrypt securely stores passwords (never plain-text)
What salting is and why same password gives different hashes
How JWT tokens are used for user authentication
Basics of building a Node.js + Express backend
How to create a simple web-based UI connected to an API
Understood the difference between hashing, encryption, and encoding
Learned how file tampering can be detected using hash comparison

Overall, this internship gave me practical exposure to real-world cybersecurity concepts that are used in actual software systems. It improved my understanding of data security and gave me confidence to work on security-related projects in the future
